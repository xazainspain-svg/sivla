# Audios de la landing

`cancion-sivla.mp3` es la canción que aportó el propietario (2:12) y es la que suena con "Escuchar". Para cambiarla o añadir más, coloca aquí MP3 u OGG **solo si tienes autorización** para publicarlos y regístralos en `src/audio/tracks.ts` (se usa el primero). Con la lista vacía la web usa un beat sintético de demostración, claramente rotulado.
